A web-based room design application built with PHP, MySQL, JavaScript, jQuery, HTML, CSS, and SVG.

## 📖 About

**Design** is a web application for creating and managing room designs.

The application allows users to register and log in, create rooms, and work with a visual room-design interface.

The design interface uses **SVG** to display room elements such as rectangles and polygons.

Users can interact with room objects and change their position and dimensions.
